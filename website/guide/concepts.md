# 核心概念

## 节目 = 一场播出

「节目」是小云播客坊的核心单元，一场带货直播、一本有声书、一期播客都是一个节目。节目由三个维度定义：

### 内容形态

| 形态 | 适合场景 |
| ---- | -------- |
| **一个人讲** | 单主播带货、宣讲、FM 独白 |
| **多人聊天** | 双人播客、访谈式直播 |
| **照着稿子读** | 有声书、新闻播报——几乎不改稿 |
| **分角色表演** | 广播剧、剧情带货——每个角色各配音色 |

### 播出方式

| 播出方式 | 合成策略 | 适合 |
| -------- | -------- | ---- |
| **现场发挥** | 说一句合成一句 | 纯互动直播，没有底稿，像真人一样和观众聊天 |
| **边播边准备** | 一段一段滚动合成 | 直播带货：主播边写稿边播，你随时能改后面的稿 |
| **全部做好再播** | 开播前整本合成完 | 有声书、预制播客：稿子不再动，音频齐了才开播 |

### 播完之后

- **循环**：播完一轮从头再来，适合无人值守的轮播场
- **收播**：播完主播说收尾词，体面下播

## 主播与节目解耦

主播（人设卡）和节目是分开的：同一个主播可以串不同的节目，同一个节目也可以换主播。音色挂在节目上（音频合成是节目级配置），主播只管人设与表达风格。

## 事件触发器

冷场自救、欢迎新人、送礼感谢、点赞里程碑这类「条件动作」是节目级开关：在节目里勾选启用哪些。评论之外的事件要不要打断播出，由节目形态说了算——照着稿子读的节目默认不被打扰。

## 话术池：一切声音的唯一出口

主播临场说的、底稿预合成的、你人工播报的，全部进同一个话术池按车道播出：打断 &gt; 插队 &gt; 常规 &gt; 垫底。所以任何来源的声音都不会叠在一起乱播。

## 评论与事件流

评论、进场、礼物先进「事件收件箱」：去重、按观众归组、5–30 秒自适应聚合、每分钟速率帽。主播像真人一样看到才回、没看到不回；回一个还是回一批由它自己判断。直播台的「事件流」选项卡可以实时看到喂给主播的每一批事件。
