# 快速上手

四步开播：**配钥匙 → 建主播 → 建节目 → 写稿开播**。

## 第一步：配两把钥匙

打开左下角「设置」，先办两件事：

- **语言模型**：AI 的脑子。一条「接入」＝服务商 + 凭据 + 一组模型。支持 OpenAI 兼容协议（DeepSeek、通义千问、豆包、Kimi、智谱）、OpenAI 官方 Responses、Anthropic（Claude、Kimi 编程端点）；协议对不上还能用「自定义接口」手填地址
- **语音合成**：主播的嗓子。接入可选火山引擎（豆包语音）、阿里云百炼；做双人播客还能接火山播客专用大模型，整期一次合成

填完再去「导演」：给全局这个 AI 大脑起个名字，指定它用哪条接入、哪个模型。

![设置](./screenshots/settings.png)

## 第二步：建主播

进入「主播团」，新建一张人设卡：名字、音色，加上性格、口癖、禁区。音色是必填的，不选主播没声音。

想用店家的声音，先去「音色库」克隆一个：要一段 10–30 秒的干净人声；百炼复刻还得把样本放到公网地址（界面里有「上传样本并取地址」）。每个音色都能先试听再决定用不用。

![主播团](./screenshots/anchors.png)

## 第三步：建节目

进入「节目」，新建一个节目，填这几件事：

1. **内容类型**：一个人讲 / 多人聊天 / 照着稿子读 / 分角色表演
2. **播出方式**：现场发挥 / 边播边准备 / 全部做好再播
3. **播完以后**：循环还是收播
4. 主题与节目说明、卡司、知识范围，以及事件规则（一行摘要，点进去勾选启用哪些触发器）

配好点「设为当前」。节目是配置模板，每次真开播的留档在「场次记录」里。形态与播出方式怎么选，见[核心概念](/guide/concepts)。

![节目](./screenshots/programs.png)

## 第四步：写稿与开播

回「直播台」。底部播放条左边选节目、定出镜主播与嗓音，中间按「启动节目」。

- **现场发挥 / 边播边准备**：直接开播，稿子边播边合成。跟右下角的导演说一句「给这场写稿」，它会自己查知识库、核对价格口径
- **全部做好再播**：先在节目卡点「底稿库」写稿（AI 写稿 / 手动新建），再点「生成节目音频」。这一步会弹「合成声音」窗口，显示「本次合成 N 段 · 约 X 分钟」，声音三选一：当前主播嗓音 / 节目声音安排（只有老节目存过自定义配置才出现）/ 选择其他音色…。定下来的声音会冻结进每一段音频，之后换主播、改人设都不会改写已经出好的音频。音频齐了再回直播台开播
- **开播之后**：左栏在「接下来 / 评论流 / 事件流」之间切，看排播、看评论、看喂给主播的事件（节目关掉「直播间动态」时只有「接下来」）。播放条上能 上一段 / 暂停继续 / 下一段 / 队列 / 结束本场，右边调音量和静音，「⋯」菜单里是人工播报和自动响应

右下角的悬浮球是导演面板，按 `Ctrl+J` 也能唤起。它会写稿、汇报思考过程、列出查过哪些资料、安排过哪些播报，遇到拿不准的事会递给你一张带选项的请示卡，点一下就行。

![直播台](./screenshots/live.png)

## 导出音频

预制节目的节目卡上就有「导出」，整场 MP3/WAV，分章或合并、响度归一，传喜马拉雅、小宇宙这些音频平台都行。「场次记录」里也能导出某一场的整场音频。

## 接入真实评论

主程序不内置任何平台 SDK，也没有模拟器。评论靠一个单独的小软件：装好抖音「直播数据助手」并打开它，把它「设置 → 智能体接口」里的**端口和令牌**抄进小云播客坊的「设置 → 连接器」，评论、礼物、进场就会流进来；连接器没开时会自动重试，你打开它自己就接上了。

画面推流有两种走法：「伴侣模式」——小云播客坊只出声，画面交给你的直播软件；「直推」——用 FFmpeg 推静态帧加混音到 RTMP。
