# 快速上手

四步开播：**配钥匙 → 建主播 → 建节目 → 启动**。

## 第一步：配两把钥匙

打开左下角「设置」，需要填两处：

- **语言模型**：主播的大脑。支持 DeepSeek、豆包、OpenAI 兼容协议（含 Responses 协议，可接 GPT）、Anthropic 等，填入 API Key 即可
- **语音合成**：主播的嗓子。支持火山引擎、阿里云百炼；做多人播客还可以接火山播客专用大模型（Podcast API）

![设置](./screenshots/settings.png)

## 第二步：建主播

进入「主播团」，新建一张人设卡：性格、口癖、禁区、编剧模式（主播自己写稿自己播）都在这里配置。想克隆店家的声音，先去「音色库」传一段 10 秒以上的干净录音，克隆完成后再回人设卡挂上。

![主播团](./screenshots/anchors.png)

## 第三步：建节目

进入「节目」，新建一个节目，选三件事：

1. **内容形态**：一个人讲 / 多人聊天 / 照着稿子读 / 分角色表演
2. **播出方式**：现场发挥 / 边播边准备 / 全部做好再播
3. **播完之后**：循环还是收播

形态与播出方式怎么选，见[核心概念](/guide/concepts)。

![节目](./screenshots/programs.png)

## 第四步：写稿与开播

回到「直播台」，选中你的节目。有稿节目直接在右侧对话框跟主播说「给这场写稿」，它会自己查知识库、核对价格口径，把底稿逐场写好。

- **边播边准备 / 现场发挥**：点「启动节目」直接开播，稿子边播边合成
- **全部做好再播**：先在节目里走一遍预合成，门禁确认音频齐全后再开播
- **开播后**：评论流进来了主播自己看着回；你随时可以人工播报、切场景、调音量、急停

![直播台](./screenshots/live.png)

## 导出音频

预制节目播完（或不播）都可以在直播台点「导出」，整场合成 MP3/WAV，分章或合并、响度归一，直接上传喜马拉雅、小宇宙等音频平台。

## 接入真实评论

主应用不含任何平台 SDK。评论由独立的「平台连接器」小程序经本地事件流喂进来；开发期可以用内置模拟器先跑通全流程。直播画面合成（摄像头 + BGM + 合成声音）推流用「伴侣模式」：小云播客坊只出声，画面在你的直播软件里自己合成。
