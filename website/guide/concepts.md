# 核心概念

## 节目是模板，场次是留档

「节目」是一份配置模板：一场带货直播、一本有声书、一期播客，都先建成一个节目，把形态、播出方式和播完策略配好，然后反复拿它开播。每真正播出去一次，就在「场次记录」里留下一条**场次**——这场谁播的、用的是什么声音、逐条说了什么、观众说了什么，只属于这一场。改节目不会动到已经播过的场次。

节目由三个维度定义：

### 内容形态

| 形态 | 适合场景 |
| ---- | -------- |
| **一个人讲** | 单主播带货、宣讲、FM 独白 |
| **多人聊天** | 双人播客、访谈式直播 |
| **照着稿子读** | 有声书、新闻播报——几乎不改稿 |
| **分角色表演** | 广播剧、剧情带货——一条稿子里几个角色轮流开口 |

### 播出方式

| 播出方式 | 合成策略 | 适合 |
| -------- | -------- | ---- |
| **现场发挥** | 说一句合成一句 | 纯互动直播，没有底稿，像真人一样和观众聊天 |
| **边播边准备** | 一段一段滚动合成 | 直播带货：边写稿边播，你随时能改后面的稿 |
| **全部做好再播** | 开播前整本合成完 | 有声书、预制播客：稿子不再动，音频齐了才开播 |

### 播完之后

- **循环**：播完一轮从头再来，适合无人值守的轮播场
- **收播**：播完主播说收尾词，体面下播

## 声音在合成那一刻定

节目里没有「声音安排」这一栏。所有合成入口——节目卡的「底稿库」、预制节目的「生成节目音频」、直播台的人工播报——都会先弹「合成声音」，在那里选这次用哪把嗓子：

- **当前主播嗓音**：跟着出镜主播走
- **节目声音安排**：只有老节目存过自定义声音时才出现
- **选择其他音色…**：接入 → 模型 → 音色，也可以直接填音色 ID；选到播客模型还要挑两位主持人和开场/结尾音乐

弹窗会先说清这次要合成多少：「本次合成 N 段 · 约 X 分钟」。确认之后才开始合成，选的这把嗓子**冻结进每一段产物**——之后换主播、改人设、改节目配置都改写不了它；想换声音就重新合成。已有段落是别的嗓音时会提醒会混音，并给你「全部重合成统一」。

## 主播与节目解耦

主播（人设卡）和节目是分开的：同一个主播可以串不同的节目，同一个节目也可以换主播。主播只管人设与表达风格；声音不挂在节目上，每次合成时单独选，所以换主播不必动节目，改节目也不会悄悄换掉已有音频。

## 事件触发器

冷场自救、欢迎新人、送礼感谢、点赞里程碑这类「条件动作」是节目级开关：在节目的事件规则里勾选启用哪些，同时也能决定要不要把直播间动态喂给主播。评论以外的事件要不要打断播出，由播出方式说了算——照着稿子读、全部做好再播的节目默认不被打扰。

## 话术池：一切声音的唯一出口

主播临场说的、底稿预合成的、你人工播报的，全部进同一个话术池，按四档排出先后：**打断 > 下一条 > 常规 > 垫底**。回评论、救急的话走「打断」立刻插进来，其余排在当前这条之后按序接着播，垫底的只在前面都空了才轮到。所以任何来源的声音都不会叠在一起乱播。

## 评论与事件流

评论、进场、礼物先进事件流：去重、按观众归组、5–30 秒自适应聚合、每分钟限速。主播像真人一样看到才回、没看到不回；回一个还是回一批由它自己判断。直播台左栏的「事件流」选项卡可以实时看到喂给主播的每一批事件。

## 冻结快照与预制门禁

开播那一刻会把这一场的导演、出镜主播、声音和策略定格成快照，整场按这份快照走，不会播到一半被后台的改动带偏。「全部做好再播」的节目开播前还要过一道预制门禁：逐段核对音频是否齐、是否还跟当前文稿对得上，缺项照实列出来、不静默跳过，并给你三条路——继续生成、重试失败项，或者先「仅播放已完成部分」。
