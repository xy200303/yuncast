# 08 · 使用流程与模块协作

> 状态：随实现更新 · 2026-10-11
> 标注约定：**✅ 已实现** / **🧩 规划中**（见 07 的分期 P1-P6）
> 面向对象：装软件、配内容、开播的人（店主 / 运营）；也是开发时的模块地图。

## 0. 全景：一次直播要经过四个阶段

```
① 准备（一次性）      ② 备场（每场）        ③ 开播（直播中）      ④ 收场（下播后）
安装 + 配置凭据        建/选场次、生成话术库   监控 + 干预 + 应急     复盘 + 沉淀
音色 / 知识库 / 剧本   预检                 插播 / 切换 / 修订     采纳改写、看数据
```

## 1. ① 准备阶段（装完软件第一次用，约 30 分钟）

| 顺序 | 去哪 | 做什么 | 为什么 |
|---|---|---|---|
| 1 | 安装包 | 装主应用；**另装连接器**（抖音「直播数据助手」）✅ | 主应用不内置平台 SDK，评论靠连接器 |
| 2 | 设置 → 语言模型 | 填 LLM 的 API Key（DeepSeek/通义/豆包/Kimi/智谱，有直达控制台按钮）✅ | 主播 Agent 的大脑，没有它主播不能开口 |
| 3 | 设置 → 语音合成 | 填 TTS 凭据（火山 AppId/Token 或百炼 API Key），点「测试发音」听到声音 ✅ | 声音不配，所有播报都会合成失败 |
| 4 | 音色库 | 新建音色：上传/录制样本 + 勾选授权 → 克隆 → 就绪后「设为默认」✅（克隆接口待核对） | 用店主本人的声音，观众才信 |
| 5 | 知识库 | 建商品卡（名称/价格/卖点/FAQ）+ 上传资料文件（PDF/Word/图片）✅ | **价格与产品细节的唯一来源**，主播报价只认这里 |
| 6 | 知识库 → 剧本 | 建剧本：场景序列（开场→痛点→讲解→互动→催单→收尾），每场写目标/要点 ✅ | 管"说什么"，骨架话术按它生成 |
| 7 | 主播团 | 建人设卡：名字、性格、口癖、背景、禁区；需要多角色（如对口相声）就加角色表（角色名+音色+口吻）✅ | 管"我是谁" |
| 8 | 🧩 演出形式 | 选/建形式：单口带货、对口相声、幽默、朗诵…（见 07 §5.6） | 管"怎么演"，与剧本正交组合 |
| 9 | 设置 → 推流 | 选伴侣模式（推荐，只出声，画面走直播伴侣）或直推 RTMP（填推流地址与密钥）✅ | 声音进直播间的通道 |
| 10 | 设置 → 连接器 | 粘贴连接器的 MCP Token（连接器「设置 → 智能体接口」里复制）✅ | 真实评论的入口 |

**这一轮的产出**：一个能开口、有声音、有知识、有人设的主播，但还不会自己讲整场。

## 2. ② 备场阶段（每场直播前，约 10-20 分钟）

| 顺序 | 去哪 | 做什么 |
|---|---|---|
| 1 | 场次 | 新建场次：名称、主题、**绑人设 + 形式 + 剧本 + 知识库范围**（🧩 目前只绑剧本） |
| 2 | 场次 | 配生成参数：每场景变体数、语气指令、音色（🧩） |
| 3 | 场次 | 点「生成话术库」→ 按场景 × 变体批量生成（🧩 P1） |
| 4 | 场次 | 审阅表格：逐条改/删/重生成，确认口径（🧩 P1） |
| 5 | 场次 | 点「预合成」→ 全部骨架话术提前合成好音频（🧩 P1） |
| 6 | 场次 | 配轮播方案：场景顺序、变体轮换、跳转规则（🧩 P2/P3） |
| 7 | 场次 | 点「加载场次」→ 预检（缺失项会明确提示）（🧩 P6） |

## 3. ③ 开播阶段（直播中）

### 3.1 开播动作（30 秒）

```
直播台 → 确认顶部场次选择器是这场 → 点「启动场次」
       （一个动作完成：应用人设/声音/BGM → 预检 → 话术库入池 → Agent 启动）
       → 点「开始推流」（或直接用直播伴侣推画面，主应用只负责声音）
       → 开连接器的评论接入：抖音直播伴侣以互动工具入口启动连接器
```

**开播只有一个入口 = 启动场次**。主播团页的「启动主播」是调试用的旁路（不绑场次、用当前人设），正式开播一律走直播台的「启动场次」。这样"这场用什么人设/形式/剧本/话术/声音"全部由场次一次性决定，不需要在多个页面手动对齐。

没选场次时可以先切到「自由模式（不加载场次）」试麦/调试，但该模式没有骨架话术与轮播方案，只靠 Agent 现场生成。

### 3.2 直播台的四个区域与用途

| 区域 | 看什么 | 什么时候看 |
|---|---|---|
| 左栏 · 话术池队列 | 即将播什么、状态（待合成/就绪/播报中/失败） | 想确认下一句是什么 |
| 左栏 · 评论流 | 观众说了什么 | 关注互动、准备人工插话 |
| 右栏 · 提词器 | **正在播的全文（句级高亮）+ 接下来 3 条 + 当前场景** | 最重要的安全阀：随时知道 AI 要说什么 |
| 右栏 · 操作面板 | 手动控制入口（下方） | 需要人工干预时 |

### 3.3 操作面板每个按钮的作用与时机

| 按钮 | 作用 | 典型场景 |
|---|---|---|
| 人工播报 ✅ | 输入文字 → 选车道（排队/下一条）→ 丢进池，合成后自动播 | 临时想补一句、纠正 AI 的口径 |
| 接管说话（按住）✅ | 暂停 AI、开麦克风、真人直接讲；松开恢复 | 观众问到 AI 答不了的、要临场发挥 |
| 插话 ✅ | 一句话插队到"下一条" | 快速打断并纠正（比接管轻） |
| 切场景 🧩 | 跳到指定剧本场景（现在禁用态待启用） | 想提前进催单 / 跳过某段 |
| 场控指令 🧩 | 换音色、调语速等（规划中） | 促销环节加快语速 |
| 调音量 ✅ | BGM 播放/音量、主音量 | 现场太吵/太静 |
| 紧急停止 ✅ | 停 Agent + 清空池 + 停当前播报（推流不断） | 说错话、价格报错、任何意外 |
| 推流开关 ✅ | 直推模式的开始/停止推流 | 直播开始与结束 |

### 3.3.1 两种控制方式：按钮 + 对话

| 方式 | 适用 | 特点 |
|---|---|---|
| **按钮**（插话/接管/切场景/调音量/紧急停止） | 需要 0 延迟、或已经明确知道要做什么 | 不经 LLM，立即生效 |
| **导演对话**（🧩 P11） | 需要"理解意图"的调整：改节奏、换语气、纠错、临时改变风格 | 自然语言下指令，AI 回执并执行；明确槽位的指令走快速解析（<100ms） |

**边界**：紧急停止与接管说话**永远走按钮**——现场要零延迟，不能等 LLM。对话里的高风险指令（清空池、跳过整场）会二次确认；每次执行都有中文回执并进事件时间线，可在数据页核对。

### 3.4 直播中三类情况怎么处理

| 情况 | 系统自动做什么 | 人需要做什么 |
|---|---|---|
| 观众评论进来 | 连接器推事件 → EventBus → 主播 Agent 收到（带老粉画像）→ 自己决定回不回、用 `insert_next` 插播回复 | 一般不用管；发现回复不当用「紧急停止」或接管 |
| 礼物/进场/点赞 | 触发器按模板直连（送礼感谢）或派任务给主播（欢迎新人） | 不用管；可在主播团里关掉不想用的触发器 |
| 库存/价格变了 | 改知识库商品 → 发事件 → 主播收到后用 `revise_item` 改**还没播**的报价话术（含竞态守卫）✅ | 改完看一眼提词器，确认口径切换了 |
| 冷场（池空） | 触发器唤起主播补货；实在没有再走 filler 暖场 → BGM 垫场 | 可以人工插话或切场景 |
| AI 说错话 | —— | 「紧急停止」→ 接管说明 → 恢复；错的话术条目已在池里标记，不会重播 |

### 3.4.1 人工接管期间

接管期间进来的评论**照常记录但不插播**（避免 AI 一恢复就连环回话）；松开接管后，主播按优先级补回重要的（价格/售后类），寒暄类忽略。

### 3.5 下播

```
点「停止主播」（池里存货会播完）→ 停推流 → 关闭连接器
```

## 4. ④ 收场阶段

| 动作 | 在哪 | 说明 |
|---|---|---|
| 场次摘要 | 数据 → 场次摘要 ✅ | 主播下播时自动复盘本场亮点与高频问题 |
| 观众画像 | 数据 → 观众画像 ✅ | 老粉互动次数、问过什么、记住的偏好 |
| 事件时间线 | 数据 → 事件时间线 ✅ | "现场发生了什么 → AI 怎么反应" 逐条可回放 |
| 本场改写清单 | 🧩 复盘列表（P5） | 现场改过的话术，逐条采纳（回底稿/存为新变体）或丢弃 |
| 运行记录对比 | 数据 ✅/🧩 | 同一场次多次开播的效果对比 |

## 4.5 导航结构：直播 · 资产库 · 数据

侧边栏按用途分三区（视觉上是分组标签 + 分隔线）：

```
直播        直播台      开播与监控（唯一开播入口：启动场次）
            场次        开播单元：绑人设 + 形式 + 剧本 + 知识库 + 话术库 + 轮播方案

资产库      主播团      人设卡（可多张，跨场次复用）+ 触发器
            知识库      商品/资料文件/剧本（价格与产品事实的唯一来源）
            音色库      克隆音色（跨场次复用）
            （演出形式  单口/相声/朗诵等表演形式 —— 🧩 规划中）

数据        数据        观众画像 / 场次摘要 / 事件时间线 / 复盘采纳

设置（底部）  全局配置：外观、语言模型、语音合成、实时语音、推流、连接器
```

**分组逻辑**：直播区是"这次要开播"（动作），资产库是"可以反复用"（素材），两者边界就是"是否需要每次重新选择"。

## 5. 板块协作关系（模块地图）

```
                    ┌──────────────── 内容准备 ────────────────┐
                    │ 知识库（商品/资料）  剧本（场景）  人设卡  │
                    │ 🧩 演出形式          音色库（克隆）       │
                    └───────────────┬──────────────────────────┘
                                    │ 被引用
                              ┌─────▼─────┐
                              │  场次     │  开播单元：绑人设+形式+剧本+知识库
                              │ (LivePlan)│  +话术库+轮播方案+声音+氛围+自动化
                              └─────┬─────┘
                                    │ 加载（写入当前配置、人设设为当前、骨架入池）
        ┌───────────────────────────▼────────────────────────────┐
        │                      运行态                             │
        │  连接器 ──事件──▶ 事件总线 ──▶ 触发器 ──┐                │
        │      （评论/礼物/进场/点赞）            │                │
        │                                        ▼                │
        │            主播 Agent（人设+形式+场次+剧本+记忆）          │
        │  知识库 ◀── search_knowledge/check_price ──┤ 工具         │
        │  记忆   ◀── lookup/remember_viewer ────────┤             │
        │                                        │ say/insert_next│
        │                                        ▼                │
        │                              ┌──────────────────┐        │
        │  人工（操作面板）────────────▶│   话术池         │        │
        │                              │ 车道·话轮·合成窗口│        │
        │                              └────────┬─────────┘        │
        │                                       │ 取 ready          │
        │                              ┌────────▼─────────┐        │
        │                              │  播放循环(TTS)    │        │
        │                              └────────┬─────────┘        │
        └───────────────────────────────────────┼──────────────────┘
                                                ▼
                        音频引擎（WebAudio）──▶ 声卡听 + 推流/直播伴侣
```

**三条不可违背的约束**：
1. **一切声音走话术池**（Agent 不能直接碰 TTS/音频）
2. **一切外部动作走连接器**（主应用不内置平台 SDK）
3. **价格与产品事实只出自知识库**（`check_price` / `search_knowledge`）

## 6. 一次直播的时序示例

| 时刻 | 谁 | 做什么 |
|---|---|---|
| T-20min | 人 | 打开场次 → 预检（提示"话术库有 6 条未就绪"）→ 等预合成完成 |
| T-10min | 人 | 加载场次（人设/形式/剧本/声音/BGM 就位）→ 选轮播方案 |
| T-5min | 人+连接器 | 直播伴侣开播 → 以互动工具启动连接器 → 主应用显示"连接器已连接" |
| T-0 | 人 | 点「启动主播」（开场白入池）→ 点「开始推流」 |
| T+2min | 系统 | 骨架轮播第 1 场景第 1 条；观众进场 → 触发器聚合 5 秒 → 主播欢迎 |
| T+5min | 系统 | 评论"多少钱" → 主播 `check_price` → `insert_next` 回复"一套 199" |
| T+12min | 系统 | 收到礼物 → 模板直连插播感谢（零 LLM 成本） |
| T+20min | 人 | 改知识库价格 199→179 → 主播 `revise_item` 改动未播的两条报价话术 |
| T+35min | 系统 | 池水位低 → 冷场自救触发器 → 主播补货；场景按时间规则推进到催单 |
| T+50min | 人 | 观众问了个 AI 答不上来的 → 按住「接管说话」亲自答 → 松开恢复 |
| T+60min | 人 | 点「停止场次」→ 停推流 → 关连接器 |
| T+62min | 系统 | 生成场次摘要；本场改写清单进复盘列表 |

## 7. 出问题时的排查路径

| 现象 | 先看这里 | 常见原因 |
|---|---|---|
| 主播不开口 | 主播团顶部徽章 + 设置→语言模型 | LLM 未配置 / Key 错 / 报错在主播团错误条里 |
| 有字无声 | 话术池条目标"失败" + 悬停看错误 | TTS 未配置 / 音色不是当前服务商的 / 余额 |
| 没有评论进来 | 状态栏"连接器"徽章 + 连接器窗口状态 | 连接器没启动 / Token 不匹配 / 伴侣没以互动工具入口启动 |
| 直播间听不到声音 | 设置→推流 模式 | 伴侣模式需要把"系统声音"或应用音频加进直播伴侣的音频源 |
| 价格报错 | 提词器 + 知识库 | 商品没建 / 价格改动后未等重合成完成 |
| AI 跑题 | 主播团 → 人设卡禁区 / 演出形式 | 禁区没写 / 形式与场景不匹配 |
| 池子老是空 | 直播台队列 + 场次话术库 | 话术库未生成 / 生成后被清空 / 场景停留时间过长 |

## 7.5 异常中断后的恢复

应用崩溃或被强杀后再启动，会提示：「上次运行异常结束（场次：xxx，播到第 N 场景、已播 M 条），是否继续本场次？」
- **继续**：加载该场次并从第 N 场景接着播（池内心条目已归档，骨架按轮播方案重新入池）
- **丢弃**：归档该次运行，重新选场次开播
