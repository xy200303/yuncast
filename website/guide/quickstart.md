# 快速上手

三步就能出声：**配钥匙 → 建项目写稿 → 合成开播**。全程一台电脑，数据存在本机。

## 第一步：配两把钥匙

打开左下角「设置」：

- **语言模型**：一条「接入」＝服务商 + 凭据 + 一组模型。支持 OpenAI 兼容（DeepSeek、通义千问、豆包、Kimi、智谱）、OpenAI Responses、Anthropic；协议对不上就用「自定义地址」手填。填好点「测试连接」直连验证，不用先保存。
- **语音合成**：阿里云百炼或火山引擎；做双人播客再启用火山「Podcast 双人播客」模型。

再到「导演」指定这个大脑用哪条接入、哪个模型。状态栏右侧会显示「导演 名字（服务商）」，没配就是红字，点一下直接跳过来。

想用自己的声音：去「音色库」点「新建音色」，准备一段 10–30 秒干净人声（无背景音乐），上传或现场录音；克隆音色绑定当时那条接入与模型，接入删掉就合不出声。

## 第二步：建项目、写稿

欢迎页点「新建项目」，起个名字就进工作台。**项目就是一个目录**：场次、稿子、对话在 `project.db`，合成音频在 `audio/`，附件在 `assets/`；整个目录拷走就是完整备份。

1. 点「启动直播」打开开播配置，先落在「写稿」这一步
2. 填「写稿要求」（商品/服务、卖点、卖给谁、风格），选好语言与内容形态
3. 点「开始写稿」——导演按项目里的场景逐段写，过程在卡片流里实时可见
4. 写的时候可以直接在导演对话里插话（「第三段短一点」「价格改成 59.9」），拿不准的它会先问你

写稿参数（语言/形态/风格/收尾）随每一轮任务书传给导演；写稿工具会按本场语言校验，比如日语场景写中文稿会被直接拒收并要求重写。

## 第三步：合成与开播

同一配置弹窗切到「合成」：

- **默认音色**：本场用谁的嗓子；个别段落可以在卡片上单独覆盖
- **主播音色**：稿子里标了主播标识（如「旁白」「客服小美」）时，这里会自动列出每个角色，逐个点「配置音色」在弹窗里选；配不全时下一步按钮是灰的
- **合成时机**：预合成（开播前全部做好）/ 边播边合（播一段备几段）/ 实时（逐句合成边生成边播）
- **音频策略**：复用现有音频，或清空重合成

点「预先合成音频」（选预合成时）或「下一步：开播设置」。到「播放」选收尾方式：

- **一遍播完**：播完最后一段，说完收尾话，下播
- **循环返场**：播完一轮回到第一段重来，复用同一批音频
- **一直播**：这一轮播完让导演接着写新内容继续播，不重播旧段

确认开播。开播后卡片流按稿子顺序走，播放条上可以上一段/下一段、暂停、跳进度；现场插话播完就结束，不参与循环复播。

右下角悬浮球是导演面板（`Ctrl+J` 也能唤起），演出中随时可以叫它改稿、插话、跳过。

## 评论互动

主程序不内置平台 SDK。装好抖音「直播数据助手」并打开，把它「设置 → 智能体接口」里的**端口和令牌**填进本应用「设置 → 连接器」，评论、礼物、进场就会流进来。

顶栏「自动响应」是唯一开关：关掉时不把任何动态交给导演（新项目默认关闭）；打开后按勾选的项目（欢迎新人、送礼感谢、点赞里程碑、冷场自救、价格变动提醒）派发。改完立刻生效，播出中也能调。

## 出声与推流

- **伴侣模式（推荐）**：本应用只出声，画面交给直播软件。点播放条右侧的喇叭，在「声音输出」里勾选虚拟声卡（VB-CABLE / VoiceMeeter，没装到设置 → 推流一键安装），推流软件里把**麦克风**选 `CABLE Output`——只有 AI 的声音，系统音乐和提示音进不来。
- **多输出**：同一个「声音输出」弹窗里可以勾多台设备、每台单独调音量。比如同时勾「系统默认 + CABLE Input」：自己听扬声器，推流软件同时采 `CABLE Output`。
- **直推 RTMP**：填服务器地址和推流密钥（抖音开播页可复制），由随包的 FFmpeg 直接推。

## 项目导入导出

「项目」菜单里可以：

- **导出项目**：生成标准 ZIP，包内含项目目录与全部音频，路径都是相对的，换台电脑直接打开
- **导入项目**：解压到「文档 / YunCast Projects」，重名自动加序号，项目 id 冲突自动换新

## 导出音频

「场次记录」里点进某一场，右上角「导出音频」：按实际播出顺序整场导出 MP3/WAV，可合并为一个文件或分文件，可选响度归一。流式播报的条目没有落文件，导出时会标注。

## 排错

- 合成没声音：设置 → 语音合成点「测试发音」；看状态栏的嗓音路由是否正常
- 开播被拦：预检会逐项列出阻断项，每项右边的按钮直达对应的设置栏目
- 推流软件收不到声音：确认输出设备已切到虚拟声卡，麦克风选的是 `CABLE Output` 而不是 `CABLE In 16ch`
