# 界面一览

左侧边栏从上到下是 **直播台、节目**，然后分两组：**资产库**（主播团、知识库、音色库）、**数据**（场次记录、统计），最下面是「设置」。底部状态栏常驻，显示 `就绪 / 播报中 / 已暂停 · 当前页面｜导演 名字（服务商）｜出镜 主播（嗓音 · 服务商）｜合成中 N｜推流状态｜连接器状态`。

## 直播台

开播主控台。左栏三个选项卡：`接下来 / 评论流 / 事件流`；节目关掉「直播间动态」时不出选项卡，直接显示「接下来」。

播控在**底部吸底播放条**：左槽选节目、定出镜主播与嗓音；中槽没开播时只有「启动节目」，开播后是 上一段 / 暂停继续 / 下一段 / 队列 / 结束本场；右槽是静音与主音量，还有一个「⋯」菜单（人工播报 / 自动响应）。

导演对话面板平时是右下角一个悬浮球（悬停提示「打开导演」），点开停靠到右侧，面板右上角能切成悬浮窗或收起来，`Ctrl+J` 也能唤起。时间线里有「思考过程」折叠块、工具卡（查了商品资料 / 安排了播报 ×4）和主播的请示卡（带一键选项）；输入框下方三个快捷按钮：暂停 / 跳过这条 / 汇报下状态。

## 节目

节目是配置模板。卡片上有节目名、主题、标签（内容类型 / 播出方式 / 绑的剧本）、底稿与音频状态，按钮是 设为当前 / 取消当前、底稿库、编辑、导出（预制节目，整场 MP3/WAV，分章或合并、响度归一）、删除，预制节目还会多一个「继续合成」。

编辑弹窗里能配：名称、剧本 / 文章、内容类型（一个人讲 / 多人聊天 / 照着稿子读 / 分角色表演）、主题与节目说明、播出方式（现场发挥 / 边播边准备 / 全部做好再播）、播完以后（循环 / 收播）、事件规则（一行摘要，点进内页勾选启用哪些触发器、要不要把直播间动态喂给主播）、卡司、知识范围。这里**没有「声音安排」这一栏**，声音在合成那一刻才选。

点「底稿库」管稿子和音频：AI 写稿 / 手动新建 / 清空全部 / 清空音频 / 提前合成全部（滚动节目）；预制节目那里还有音频进度区，能逐单元看状态并重试、导入外部音频。

「合成声音」弹窗是所有合成入口的统一前置，先告诉你「本次合成 N 段 · 约 X 分钟」，再让声音三选一：① 当前主播嗓音；② 节目声音安排（只有老节目存过自定义配置才出现）；③ 选择其他音色…（内嵌音色选择器：接入 → 模型 → 音色，也能手填音色 ID），选到播客模型还要指定两位主持人和开场 / 结尾音乐；已有别的嗓音的成品会给混音提醒和「全部重合成统一」。**声音就是这时候定下来的：选完冻结进每一段产物，之后换主播、改人设都不会改写已有音频。**

![节目](./screenshots/programs.png)

## 主播团

人设卡列表，点开弹窗配性格、口癖、禁区等。主播只管人设与表达风格，和节目是分开的：同一张卡能串不同节目，同一个节目也能换主播。

![主播团](./screenshots/anchors.png)

## 知识库

条目 / 资料文件 / 剧本。商品价格有护栏——主播报价只认这里核过的口径，不会自己编数字；也可以用连接器从抖音商城同步商品。

![知识库](./screenshots/knowledge.png)

## 音色库

云端音色加克隆音色。克隆要一段 10–30 秒的干净人声；用百炼复刻还得把样本传到公网地址，界面里有「上传样本并取地址」帮忙。每个音色都能先试听。

![音色库](./screenshots/voices.png)

## 场次记录

每场开播的完整留档：逐条话术、评论、事件、观众画像、节目摘要，支持逐条试听、整场音频导出、删除场次。

![场次记录](./screenshots/sessions.png)

## 统计

概览 / 排行与热词 / 用量。用量按节目归组，看 LLM tokens 和 TTS 字符，带 30 天趋势。

![统计](./screenshots/stats.png)

## 设置

外观 / 导演 / 语言模型 / 导演手册 / 语音合成 / 推流 / 连接器 / 关于。

**导演**是全局唯一的 AI 大脑：起个名字，选一条接入和一个模型。**语言模型**里一条「接入」＝ 一家服务商 + 一份凭据 + 一组模型，支持 OpenAI 兼容（DeepSeek、通义千问、豆包、Kimi、智谱）、OpenAI 官方 Responses、Anthropic（Claude 与 Kimi 编程端点），另有「自定义接口」可手填地址。**语音合成**接火山引擎（豆包语音）或阿里云百炼，做双人播客还能接火山播客专用大模型、整期一次合成。**推流**分伴侣模式（小云播客坊只出声，画面交给你的直播软件）和直推（FFmpeg 静态帧 + 混音推 RTMP）。

评论接入单独说：「连接器」靠一个单独的小软件——抖音「直播数据助手」。装好打开它，把它「设置 → 智能体接口」里的端口和令牌抄进这里，评论 / 礼物 / 进场就会流进来。主程序不内置任何平台 SDK，也没有内置评论模拟器。
