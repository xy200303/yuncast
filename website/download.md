# 下载与安装

## Windows x64

前往 [Releases](https://github.com/xy200303/yuncast/releases/latest) 下载最新安装包：

```
小云播客坊 Setup <版本号>.exe
```

双击运行，按向导安装即可。

::: warning SmartScreen 提示
安装包没有代码签名。Windows 可能弹出「Windows 已保护你的电脑」——点「**更多信息**」→「**仍要运行**」即可。
:::

## 系统要求

- Windows 10 / 11（64 位）
- 稳定的网络（LLM 与 TTS 走云端 API）
- 需要直播推流时，建议 8GB 以上内存

## 卸载与数据

卸载程序不会删除你的数据。主播、节目、音色库等数据保存在 `%APPDATA%\YunCast`，需要彻底清空时手动删除该目录。
