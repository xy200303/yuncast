# 快速上手

四步走完就能出声：**配钥匙 → 建主播 → 建节目 → 写稿开播**。全程在一台电脑上完成，数据存在本机。

## 第一步：配两把钥匙

打开左下角「设置」，先配「语言模型」和「语音合成」两栏，再到「导演」指定全局用哪条接入、哪个模型。

- **语言模型**：一条「接入」＝服务商 + 凭据 + 一组模型。协议按服务商实际接口选：OpenAI 兼容（Chat Completions，DeepSeek、通义千问、豆包、Kimi、智谱都走它）、OpenAI Responses、Anthropic Messages（Claude 与 Kimi 编程端点）；协议对不上就用「自定义接口」手填 API 地址。模型名要填服务商文档里的模型 ID，填错会在「测试连接」或开播时报错。
- **语音合成**：接入可选火山引擎（豆包语音）或阿里云百炼；做双人播客再选火山「Podcast 双人播客」模型，整期音频一次合成。接入里勾选了哪些模型，这条接入就能合成哪些内容、用哪些音色。

「导演」是全局唯一的 AI 大脑，主播团里的卡只管人设与嗓音。配好后状态栏右侧显示「导演 名字（服务商）」，没配就是红字，点一下直接跳过来。

![设置](./screenshots/settings.png)

## 第二步：建主播

进入「主播团」，点「新建人设卡」：名字、音色，加上性格、口癖、禁区。**音色是必选的**，不选这张卡就没有声音。

想用自己的声音，先去「音色库」点「新建音色」，打开「新建音色（声音克隆）」弹窗：准备一段 10–30 秒的干净人声（无背景音乐），选好接入与目标模型，上传文件或直接现场录音，勾选授权后提交。火山复刻在服务商侧异步训练，卡片状态会从「训练中」变为「就绪」；百炼复刻只认公网地址，用界面里的「上传样本并取地址」把本地样本换成直链。每个音色都能先试听。

克隆音色绑死克隆时那条接入与目标模型，接入删掉后这些音色就合不出声（音色记录本身保留）。

![主播团](./screenshots/anchors.png)

## 第三步：建节目

进入「节目」，点「新建节目」，填这几件事：

1. **内容类型**：一个人讲 / 多人聊天 / 照着稿子读 / 分角色表演
2. **播出方式**：现场发挥 / 边播边准备 / 全部做好再播
3. **播完以后**：播完停止 / 循环播放（现场发挥没有这一项）
4. 名称、剧本 / 文章、主题与节目说明、卡司、知识范围，以及事件规则（点进去勾选启用哪些触发器、要不要把直播间动态喂给主播）

配好点「设为当前」。节目是配置模板，每次真开播的留档在「场次记录」里。三种播出方式的差别与选法见[核心概念](/guide/concepts)。

## 第四步：写稿与开播

回「直播台」，底部播放条左槽选节目（出谁由节目卡司决定），中槽点「启动节目」。点下去先弹「开播确认」：导演、卡司、播出方式、互动开关，加上一份预检清单（导演大脑、嗓音路由、剧本、连接器、推流）。有阻断项时「确认开播」是灰的，每项右边的按钮直达对应页面或设置栏目。

- **现场发挥 / 边播边准备**：确认开播就开始出声，稿子边播边合成。跟右下角导演说一句「给这场写稿」，它会自己查知识库、核对价格口径
- **全部做好再播**：先写稿再合成。写稿在节目卡的「底稿库」里（AI 写稿 / 手动新建），合成入口统一弹「合成声音」窗口，先告诉你「本次合成 N 段 · 约 X 分钟」，再让声音二选一——卡司嗓音 / 选择其他音色…（接入 → 模型 → 音色，也能手填音色 ID）；选到播客模型还要挑主持人 A、B 和开场、结尾音乐
- **声音冻结**：合成时选定的声音写进每一段产物，之后换主播、改人设、改节目配置都改写不了它；要换声音只能重新合成。已有别的嗓音的成品时会给混音提醒，并给一个「全部重合成，统一为本次选的声音（旧音频清掉）」
- **开播之后**：左栏在「接下来 / 评论流 / 事件流」之间切，节目关掉「直播间动态」时只有「接下来」。播放条上是 暂停继续 / 跳过当前这条 / 队列 / 结束本场，预制节目另有上一章、下一章和可拖动的进度线；右边是静音与主音量，「⋯」菜单里是 人工播报 / 自动响应

预制节目音频不齐时不会静默开播：弹窗逐项列出缺哪一段、为什么缺，只给两条路——「继续生成（补齐音频）」补齐全部缺项，或「仅播放已完成部分」先播有的。

右下角的悬浮球是导演面板，按 `Ctrl+J` 也能唤起。它会写稿、汇报思考过程、列出查过哪些资料，遇到拿不准的事递给你一张带选项的请示卡，点一下就行。

## 导出音频

节目卡上点「导出」，整场 MP3 或 WAV：范围是这一节目的全部内容单元（按内容类型显示为段 / 个环节 / 章 / 场），方式分「分章导出」和「合并为一个文件」，可开「统一音量」做响度归一，文件名模板支持 `{节目名}` `{序号}` `{章节名}`。缺音频的会先列出来，「仅导出已完成部分」能先导出一份。开始导出前要先选输出目录。

「场次记录」里也能导出某一场：点进那一场，右上角「导出音频」按实际播出顺序导出整场，管线相同。

## 接入真实评论与推流

主程序不内置任何平台 SDK，也没有内置评论模拟器。评论靠一个单独的小软件：装好抖音「直播数据助手」并打开它，把它「设置 → 智能体接口」里的**端口和令牌**抄进小云播客坊的「设置 → 连接器」，评论、礼物、进场就会流进来。连接器没开时主程序按 1 秒到 30 秒退避自动重连，你把它打开就自己接上了。

画面推流有两种走法：「伴侣模式」——本应用只出声，画面交给你的直播软件；「直推」——用随包分发的 FFmpeg 推静态帧加混音到 RTMP，需要在「设置 → 推流」填服务器地址和推流密钥（抖音开播页可复制）。
