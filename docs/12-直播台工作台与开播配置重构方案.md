# 直播台工作台与开播配置重构方案

> 状态：**方案待评审**（未动代码）
> 来源：甲方试用反馈与后续讨论（2026-10-18）
> 关联：`docs/10-节目化改造方案.md`（编排模型）、`docs/11-段卡片播放与TTS真人化方案.md`（段卡片）
> 本文为单一版本，已合并讨论过程中的全部修订；与旧稿冲突处以本文为准。

---

## 一、背景与结论

甲方 5 条反馈：

1. 切节目要立刻看到全部话术稿，已播置灰；每条能「从此处播」「仅播此条」。
2. 状态混乱：合成失败被当成没话术 → 触发 Agent 重生成 → 合成死循环。
3. 开播时才配主播/音色/语言；现在是"主播里配音色、节目里配主播"层层嵌套；音色没声明泰语也能播，太死板；有些模型根本不存在。
4. 跨境场景只有目标语言，看不懂在播什么，需要目标语 + 中文对照。
5. 资产互相耦合，操作链条太长，希望资产库只做静态描述，节目只是可复用资产。

**结论：三个结构问题，不是五个 bug。**

| 甲方感受 | 真实成因 |
|---|---|
| 切节目看不到稿、状态混乱 | 直播台是"播放器"不是"工作台"：全量底稿不展示，已播/失败/跳过没有出口 |
| 失败 → 以为没稿 → 重生成 → 死循环 | 失败条目不进池、也不可见；池空判定把"有失败"当"真空"触发补货，根因未消除必然复发 |
| 主播含音色、节目含主播 | 资产层互相绑定：`personas.voiceId` 必选、`programs.personaIds` 是卡司 |
| 语言/音色对不上、模型不存在 | 语言在节目上、音色在主播上，两者没有能力声明；模型清单硬编码 |
| 跨境看不懂 | 话术只有目标语言一个字段 |

## 二、新模型：三层

```
① 资产层（可复用，互不引用）
   剧本    场次序列（开场→痛点→讲解→互动→催单→收尾），每场只写目标/时长/要点/CTA
   素材    条目（正文 / 附件 / 链接）
   主播卡  姓名 / 性格 / 口癖 / 背景 / 红线（人设，不含声音）
   音色    音色 id / 接入 / 模型 / 语种实测记录 / 风格指令 / 是否流式

② 本场层（一次开播，唯一的绑定处）
   引用剧本 + 主播（可多）+ 每个主播的音色 + 话术语言 + 三个播出开关
   ↓ 生成
   本场话术：按 剧本场次 × 素材 × 主播 × 语言 × 风格 生成（语言只影响文本，不进 TTS 参数）

③ 运行时层
   话术队列 / 状态机 / 水位 / 三条合成车道 / 失败与重试 / 双语对照
```

**三条纪律**

1. 资产之间零引用：改主播不影响剧本，换音色不动主播卡，同一剧本换人播不用重配。
2. **话术是本场产物**：绑主播、绑语言、绑风格，换主播/换语言即失效并提示重写。想复用只能显式「另存为话术模板」，模板记录生成上下文，换人导入时标黄提示。
3. 本场的改动不写回资产。

## 三、剧本（原「节目」）只描述结构

```
第 1 场 开场留人  目标：3 秒不划走      约 1 分钟  要点：钩子 + 今天只讲一只杯子
第 2 场 痛点      目标：说出 3 个真实痛点  约 2 分钟  要点：串味 / 发霉 / 漏水
第 3 场 讲解      目标：4 个卖点讲透     约 3 分钟  素材：保温杯
第 4 场 算账      目标：价格不贵        约 1 分钟  素材：价格口径
第 5 场 催单      目标：下单           约 1 分钟  CTA：左下角
```

台词由本场生成。剧本里硬编码台词，换人就废——这是现在混乱的源头之一。
例外：有声书/逐字稿需要逐字内容，剧本上加 `mode: outline | verbatim`，两种语义分开。

## 四、导入剧本 = 引用 + 本场覆盖

- 导入只建立引用：工作台拿到场次序列与每场生成目标，剧本数据不动。
- 工作台里改台词/删段/调语气 → 写入**本场覆盖层**（`session_items`），不写回剧本。
- 需要沉淀时显式点「把这一场存回剧本要点」：只存结构性收获（有效钩子、痛点顺序），不存整段台词。
- 避免"我改了一场，下次开播怎么全变了"。

## 五、开播配置：每次开播必经的弹窗

### 5.1 流程

```
直播台 → 导入剧本（只载入结构与话术）
      → 点「启动直播」
      → 弹「直播配置」（一屏看完）
      → 预检（仅阻断项拦截）
      → 开播
```

每次必须过一遍弹窗，不做"上次配置直接开播"的快捷路径——这一场用什么人、什么嗓子、什么语言、读什么稿、用旧音频还是重合成，都在开播那一刻确认并写进场次记录。字段可**预填上次的值**（减少输入），但必须人点确认，预填值不写回资产。

### 5.2 弹窗结构

```
┌ 直播配置 ──────────────────────────────────────────────────┐
│ 剧本：保温杯专场           底稿 5 场 / 23 条 · 中文          │
│                                                            │
│ ① 话术语言   [中文 ▾]   决定写什么语言；不传给 TTS，逐条可覆盖 │
│ ② 主播       [小满 ×] [阿哲 ×] [+ 添加]   ← 多选，主主播打星 │
│ ③ 音色       小满 → [小满·带货女声 ▾]  试过：中文 ✓ 英文 ✓   │
│              阿哲 → [沉稳男声 ▾]        试过：中文 ✓           │
│              ⚠ 这个音色没试过泰语——多数模型照样能读，先试听一条 │
│ ④ 播出方式   ( ) 一遍播完  (•) 循环返场  ( ) 播完停止        │
│ ⑤ 合成时机   ( ) 预合成  (•) 异步边播边合  ( ) 实时流式      │
│              主内容按此档；互动回复固定走实时流式            │
│ ⑥ 音频策略   (•) 复用现有音频   18 条就绪 / 5 条需合成         │
│              ( ) 清空音频重新合成  预计 3 分 20 秒 · 约 23 次调用 │
│              [试听这一段]                                   │
│                                                            │
│ 互动：☑ 读评论区  ☑ 突发事件交给导演                        │
│                                    [取消]  [确认开播]        │
└────────────────────────────────────────────────────────────┘
```

### 5.3 音频策略（用旧音频还是重合成）

| 选项 | 行为 | 界面写清楚 |
|---|---|---|
| **复用现有音频**（默认） | 就绪段直接播；缺失/已失效的段边播边补 | 「18 条就绪，开播即出声；5 条待合成会边播边补」 |
| **清空音频重新合成** | 先清空本场全部音频，按当前音色/语言全量重合成，**合成完才开播** | 「清空 23 段，预计 3 分 20 秒、约 23 次 TTS 调用；期间不能开播」 |

- 清空带二次确认（勾选"我知道会重新计费"）。
- 重合成时弹窗内显示 N/M 进度，可取消；取消回落到"复用现有音频"。
- 单条也能「清空这条音频」，不必整场重来。

### 5.4 预检规则

| 检查项 | 级别 |
|---|---|
| 剧本没有话术 | 阻断：「先写稿，或勾选无限生成」 |
| 音色模型 id 不存在 / 接入已删 | 阻断，给替代项 |
| 语言不在音色声明支持里 | 降级为**提示**（不阻断、不需确认，建议试听一条；语言不传给 TTS，见第十六节） |
| 导演大脑没配 | 警告：播照常，但没有智能补货/互动 |
| 评论区未接入 / 推流未配 | 警告（沿用现有预检） |

## 六、合成时机：三档，且按车道定

| 档 | 行为 | 首字延迟 | 适用 | 代价 |
|---|---|---|---|---|
| **预合成** | 开播前整段合成完再出声 | 0 | 有声书、宣讲、播客、逐字稿 | 改一个字要重合成 |
| **异步边播边合** | 播 A 时合成 B/C，保持 N 段提前量（默认 3） | 补货跟不上才等 | 带货、循环话术、长播 | 需水位管理，补货慢于消耗会冷场 |
| **实时流式** | LLM 边说边分句，每句立刻合成立刻播，首句优先，可打断 | 0.8–2 秒 | 互动直播、回评论、突发应对 | 逐句语气不如整段连贯；依赖模型流式能力；并发与成本更高 |

**合成时机是"按车道"定的，不是全场一个开关：**

```
车道 A · 主内容（话术稿）     → 预合成 / 异步边播边合（本场配置决定）
车道 B · 互动回复（评论/进场）→ 固定实时流式，不占水位、不排预合成队列
车道 C · 突发 / 插播          → 实时流式，最高优先级
```

- 互动进来 → 主话术 duck 淡出 → 实时回复 → 恢复。
- 播放条上每条标出走的哪档（`预`/`异步`/`实时`），实时档显示首字延迟。
- 实时档连续 2 句失败 → 用预置短句兜住 + 提示卡，绝不静默。
- **前置依赖**：百炼 `qwen3-tts-flash`/CosyVoice、火山 `seed-tts` 系列的**流式接口与并发上限**需对官方文档确认（见第十六节）。

## 七、工作台布局

```
┌───────────────────────────────────────────────────────────────────┐
│ 本场：保温杯专场  剧本[带货·保温杯▾] 主播[小满★ 阿哲] 语言[中文▾] 预设[带货▾] │
├──────────────────────────────┬────────────────────────────────────┤
│ 剧本大纲（5 场，可收起）       │  当前播出                          │
│  ① 开场留人  2/3 已播         │   「先别划走，今天就聊一只杯子…」   │
│  ② 痛点      ⏳ 生成中        │   中文对照 …                       │
│  ③ 讲解      ⬜ 待生成        │   [从此处播] [仅播此条] [重写这条]  │
│  ────────────────────────    │  ──────────────────────────────    │
│ 话术（23 条）                 │  导演 / 生成管理                    │
│  ● 小满 01 …已播              │   水位：还能播 4 分 12 秒           │
│  ● 小满 03 …在读              │   合成队列 3 / 生成中 1 场          │
│  ● 阿哲 04 …合成中            │   失败 1 条 → [重试][换音色][跳过]  │
│  ⚠ 05 失败 ▸ 原因 + 动作       │                                    │
├──────────────────────────────┴────────────────────────────────────┤
│ ▶ 03/23 ██████▓▓▓▓▓░░░░ 还能播 4 分 12 秒  🔊 ⏸ ⏭ 无限生成[开] 结束本场 │
└───────────────────────────────────────────────────────────────────┘
```

四个区域各司其职：

- **顶栏是本场配置**（等价于直播伴侣的"场景"）：换主播/音色/语言都在这里，换完按热切规则提示。
- **左上剧本大纲**：让人知道"为什么说这些"，每场状态一眼可见。
- **中栏是歌词式话术流**：过去、当前、未来都在（见第八节）。
- **右侧导演 + 生成管理**：对话 + 水位 + 合成/生成队列 + 失败入口；agent 不再是黑盒。

## 八、中栏：歌词式话术流

### 8.1 一条连续的流

```
● 小满  01  刚刚那批货，报关单我全留着           0:42  ✓      ← 已播：45% 不透明
● 小满  02  我第一次跑海外仓是 2019 年           1:18  ✓
● 小满  03  ปกติแล้วพ่อค้าส่วนใหญ่จะ...           ◉ 在播       ← 在读：3px 强调竖条 + 浅底
           其实大部分商家……
● 阿哲  04  那你说的这个价，是什么价？             ⏳ 合成中
⚠          05  该音色未声明泰语                              ← 失败：行内展开，不隐藏
           [重试] [换音色] [跳过] [改稿]
● 小满  06  我们仓库在深圳，三天到曼谷             ⬜ 待生成
```

- 过去/当前/未来同一条流，只靠颜色和透明度区分：已播 45% 灰、当前正文色 + 竖条、未来正常略淡。
- 默认显示"最近 10 条已播 + 当前 + 后 20 条"，两端可「展开全部」。
- **当前条固定停在视口 38% 高度**（下方留出"接下来要说什么"）。
- 左栏剧本大纲默认收成 40px 窄条（只显示 ①②③ 与状态点），把宽度让给话术流。
- 单击 = 选中（右侧显示详情/编辑），行尾 `▶` 才是「从此处播」——播放中误触不跳播。

### 8.2 三种显示模式

栏目头部切换，按场次记住（也记全局偏好）：

| 模式 | 排版 |
|---|---|
| 播放语言 | 只显示 `textTarget` |
| 翻译语言 | 只显示 `textZh`，字号同正文 |
| 双语 | 目标语正文 + 下方中文小字（0.85 倍字号、60% 不透明），贴在条目内部，不跨条合并 |

细节：逐条语言覆盖的行首标 `TH`/`EN`；翻译缺失显示 `—` + `+ 翻译`；超长条目默认 3 行可展开。

### 8.3 自动滚动

1. 切条时平滑滚动（200ms）到 38% 位置；
2. 用户手动滚动 → 暂停跟随，右下出现「回到当前 ▶」；
3. 追加新条目：未手动浏览就继续跟随，否则只在末尾提示"新增 N 条"；
4. 失败条目留在真实位置不挪走；切条时不重排、不闪。

### 8.4 配色

| 状态 | 表现 |
|---|---|
| 已播 | 45% 不透明 + 行尾 `✓` |
| 在读 | 3px 强调色竖条 + `#eef3ff` 浅底 + `◉ 在播` |
| 待播（已合成） | 正文色 + 时长 |
| 合成中 | 正文色 + `⏳` 与细进度 |
| 待生成 | 60% 不透明 + `⬜` |
| 失败 | 行内浅红提示条 + 原因 + 三个动作 |

## 九、水位放进进度条

```
███ 已播      ▓▓▓ 已就绪缓冲      ░░░ 未合成/待生成
├─────┼──────────────────┼─────────────────────────────┤
0                                                  现在
```

- 缓冲段每合成好一条就往右长一截，"水在往里加"看得见。
- 文案：`还能播 4 分 12 秒 · 就绪 12 条 / 未就绪 3 条`。
- 无限生成模式没有终点：右端流动虚线，文案 `已播 18 条 · 缓冲 6 条 · 生成中 1 条`。
- 条上画 2 分钟安全刻度，低于它变琥珀色并提示"快见底了"。

## 十、段即条目：单条操作面

1 条 = 1 段 = 1 次合成单位（`draft_units` / `pool_items` 已是该粒度，模型不用改）。缺的是把能力露出来：

| 能力 | 后端现状 | 界面要做 |
|---|---|---|
| 看历史（已播） | `pool_recent` + 场次记录已有 | 队列改成本场全量（含已播），歌词流展示 |
| 编辑话术 | `pool_revise`（未播）/ `draft_edit`（自动重合成） | 条目编辑入口，保存即作废旧音频重合成 |
| 从某条开始播 | 池顺序可调 | 行尾「▶ 从此处播」→ 重排到队首 |
| 单条重合成 | `draft_units.rendered` 单条状态已有 | 「重合成」按钮 + 进度 + 失败原因 |
| 试听 | `AudioPipeline` 有 aux 槽，不影响主播出 | 「试听」接 aux，20 秒自动停 |

**三条硬语义**

1. **历史不可变**：已播条目原样保留（那条音频就是观众听到的）；编辑已播 = 生成新版本（标 v2），排在队尾或指定位置，不回改历史。
2. **重播 ≠ 重合成**：「重播这条」播旧音频（免费瞬时）；「重合成」才调 TTS（计费、有耗时），按钮上标代价。
3. **段 vs 章**：编辑/重合成/试听/点播粒度永远是段；章级预渲染只是"先合完再开播"的门禁，章里某段改了 → 该章判过期，可只重合成受影响的那几段。

## 十一、多主播：每条显示说话人

双人相声、访谈、团体播报都需要"这句是谁说的"。数据层已具备：`draft_units.persona_id`、`pool_items.source_actor_id`、两条都存 `voice_id` 快照。

### 11.1 显示

- 行首主播徽标 = 固定色点 + 名字（或角色名，如「逗哏／捧哏」）。
- 色板固定 4 色（蓝/橙/绿/紫），超过 4 人用首字缩写。
- 顶部图例带音色：`● 小满 · 小满带货女声   ● 阿哲 · 沉稳男声`，点击进热切换。
- 当前播出区：`当前：小满 · 音色：小满带货女声`。
- 进度条叠加**说话人时间线**（按段着色），一眼看出单口还是对口。
- 单人节目不显示徽标，避免噪音。

### 11.2 配置

- 开播配置里主播多选（1~N），**逐个指定音色**；"主主播"只是无标注段落的默认人。
- **音色故障按主播隔离**：某人的音色坏了只影响他的条目，其他人照播，绝不全场停。

### 11.3 生成与播出

- 剧本场景支持对话体：每段带 `speaker`，agent 写稿必须输出说话人。
- 段间停顿可配：对口 300–600ms，独白 400–800ms。
- 抢话/叠话本期不做，用更短停顿近似。
- 编辑时可改"这句谁说的" → 用该主播音色重合成该条。

## 十二、播出策略：三个正交开关 + 四预设

| 开关 | 取值 |
|---|---|
| 内容来源 | 本场话术（有限）/ 边播边无限生成 |
| 合成时机 | 预合成 / 异步边播边合 / 实时流式 |
| 收尾方式 | 一遍播完停 / 循环返场 / 一直播下去 |

界面只露 4 个预设，"高级"里才展开三个开关：

| 预设 | 组合 | 典型 |
|---|---|---|
| 有声书 / 播客 | 本场话术 + 预合成 + 播完停 | 一期定了就不改 |
| 带货 | 本场话术 + 异步边播边合 + 循环 | 底稿循环、缺了补 |
| 纯互动 / 闲聊 | 无限生成 + 实时流式 + 一直播 | 没底稿，像真人聊天 |
| 宣讲 / 发布 | 本场话术 + 预合成 + 循环 | 展会循环讲解 |

---

## 十三、状态机与防死循环

```
未合成 → 合成中 → 就绪 → 在读 → 已播
                     ↘ 失败（原因 + 重试次数）→ 重试 / 跳过 / 换音色
```

三处断路器：

1. **失败可见**：失败条目留在列表、标红、带原因，不从界面消失。
2. **池空分流**：池空时先看有没有失败条目——有失败 → **不触发补货**，只发提示卡「有 3 条合成失败，先重试或换音色」；真没内容才允许 agent 写稿。
3. **熔断与预算**：同一条失败 2 次即停止自动重试，只留手动按钮；同一场次"自动补货"5 分钟内最多 2 次，到顶即停并说明。

---

## 十四、热切换规则

原则：**正在出声的那一条永远不被打断**；所有切换都要回答"从哪条起生效、已合成的怎么办"。

| 项 | 能否中途切 | 生效点 | 处理 |
|---|---|---|---|
| 音量 / BGM / duck / 插播 / 跳过 | 随时 | 立刻 | 无 |
| 循环、无限生成开关 | 可以 | 下一条 | 无 |
| 音色 | 可以 | 下一条 | 弹影响预览：未播已合成的 N 条 → 保留 / 重合成；交界 80ms 淡入淡出；实时车道预热新连接 |
| 主播（换班） | 需换班流程 | 过渡语之后 | 播一句自动生成的过渡 → 未播话术按新人设重写（默认）/ 保留 / 丢弃；场次记录分段 |
| 语言 | 不建议 | 只有换本场 | 中途换语言 = 结束本场重开；个别条想换语言用逐条覆盖 |

配置条每项带角标：`🔒` 本场锁定 / `⟳` 换班 / `⚡` 热切 / `⏭` 下一条生效。
想立刻改变当前这条，用「掐掉这条」或「跳过」——把"改配置"和"中断播出"分成两个动作。

## 十五、双语话术

- 话术条目两个字段：`textTarget`（播出语言，就是喂给 TTS 的文本）与 `textZh`（中文对照，不发声）。语言信息只体现在文本里，不做参数传递。
- 生成时一次产出两份：外语节目**强制**要对照，中文节目可空。
- 播出区目标语大字 + 中文小字（可折叠）；底稿列表展开看对照。
- 导出可选：只导目标语 / 目标语 + 对照双栏。

## 十六、语言与音色：语言不是参数，语种靠实测 + 模型清单核对

### 16.1 关键事实：语言不传，靠文本本身

有些模型（尤其多语模型）不接受 `language` 参数，但只要**输入文本是泰语，它就照读**。所以合成请求里**不再显式传语言**：

```
TTS 请求 = 文本 + 音色 + 风格指令（+ 模型/接入）
语言 = 文本的属性，不是参数
```

推论：

- 「话术语言」只决定**写什么语言**，不进 TTS 请求；换语言就是换文本，不是换参数。
- 音色的"支持语言"从**硬能力声明**降级为**实测记录**：`中文 ✓ / 英文 ✓ / 泰语 未试`。
- 校验里**取消语言阻断**：语言永不阻止开播；只有"模型 id 不存在 / 接入已删"才阻断。
- 每对「音色 × 语种」可以存一条实测样本（来自 `voice_calibrate` / `voice_transcribe` 或手动试听），界面显示 `试过` / `未试`，未试的给一句"先试听一条"的建议，而不是"不支持"。

| 情况 | 表现 |
|---|---|
| 音色在该语种下试听过且通过 | 绿色 `试过 ✓` |
| 没试过这个语种 | **提示**（黄色小字）：「这个音色没试过泰语，多数模型照样能读，建议先试听一条」，**不阻断、不需要确认** |
| 模型 id 不存在 / 接入已删 | 红色阻断，给替代项 |

> 适配层可选：若供应商确实支持 `language` 参数，作为**可选提示**透传（只在接入适配器里做，不参与 UI 校验）；不支持的接入直接忽略。是否透传不影响开播。

### 16.2 模型清单核对（待办）

逐条对官方文档确认：**模型 id 是否存在、支持哪些语种、是否支持风格指令、是否支持流式、并发上限**。

- 百炼：`qwen-audio-3.0-tts-flash`、`qwen3-tts-flash`、`qwen-audio-3.1-tts-flash`、`cosyvoice-v2`、`cosyvoice-v3-plus`、`cosyvoice-v3-flash`、`cosyvoice-v3.5-plus`、`cosyvoice-v3.5-flash`
- 火山：`seed-tts-2.0`、`seed-icl-2.0`、`seed-icl-1.0`、`seed-tts-1.0`

结论做成**配置化清单文件**（不散落在代码常量里），不存在的删掉，存疑的标「实验性」。

## 十七、数据模型与迁移

```
scripts（剧本）        id, name, mode(outline|verbatim), scenes[{id,title,goal,minutes,keyPoints,cta}]
materials（素材）       条目 + 附件（不动）
personas（主播卡）      去掉 voiceId
voices（音色）         + 语种实测记录 langTrials[{lang, sampleBlob, verdict, at}]、模型、接入、是否流式
sessions（本场）        scriptId, personas[{id,voiceId,lead}], contentLanguage, preset,
                       genMode, synthMode(pre|async|realtime), endMode, audioPolicy(reuse|rebuild)
session_items（话术）   sessionId, sceneId, order, personaId, textTarget, textZh, language,
                       status, failReason, retryCount, audioRef, voiceId, source(script|agent|manual), version
templates（话术模板）   sessionId 快照 + 生成上下文（personaId / language / style）
```

迁移（umzug，新增 `0016-decouple-assets`）：

| 变更 | 处理 |
|---|---|
| `programs` → `scripts` | 保留场次与素材范围；`personaIds` 丢弃，`language` 降级为写稿默认 |
| `personas.voiceId` | 迁成"该主播的默认音色建议"，开播配置预填用，不再是必填校验 |
| 话术条目 | + `textZh`、+ `failReason`、+ `retryCount`、+ `version` |
| 历史场次 | 不动，按当时快照渲染 |

## 十八、Agent 职责收窄

- **继续做**：写稿、改稿、回评论、回答导演提问、按指令插播。
- **不再做**：合成失败自愈、状态修复、自动重试、看到池空就无脑补货。
- 失败以卡片交给导演：「第 12 条合成失败：模型返回 401 / 音色不可用（重试 2 次已熔断）→ 换音色 / 跳过 / 改写」。语言不匹配不再是一种失败——语言只影响文本。
- 写稿时从**当前场次配置**取语言与主播名单，不再从剧本读卡司。

## 十九、分期

| 期 | 内容 | 预估 |
|---|---|---|
| **P0 止血** | 失败可见 + 池空分流 + 熔断 + 话术全量列表（含已播）+ 从此处播/仅播此条/试听/单条重合成/编辑 | 2–3 天 |
| **P1 工作台** | 本场会话模型（剧本/主播/音色/语言/开关）+ 开播配置弹窗 + 导入剧本（引用 + 覆盖层）+ 歌词式中栏 + 水位条 | 4–6 天 |
| **P2 播出策略** | 三开关 + 四预设 + 无限生成 + 说话人时间线 | 3–4 天 |
| **P3 实时车道** | 分句流式合成、打断、duck、失败降级 | 3–4 天 |
| **P4 语言与能力** | 双语对照、语种实测记录（音色×语种试听样本）、模型清单核对（含流式能力） | 3–5 天 |

## 二十、验收对照

| 甲方原话 | 方案落点 | 怎么验 |
|---|---|---|
| 切节目立马显示全部话术稿，已播灰色 | 中栏全量歌词流 + 状态徽标 | 切 3 个剧本，条数与话术数一致 |
| 每条支持从此处播 / 仅播此条 | 行尾动作 | 播到第 5 条时点第 2 条「从此处播」，核对顺序 |
| 失败→以为没稿→重生成→死循环 | 失败可见 + 池空分流 + 熔断 | 选不支持的语言开播，3 分钟内只失败一次、弹提示且不再生成 |
| 开播才配主播/音色/语言 | 开播配置弹窗（每次必经） | 新建主播不需选音色；新建剧本不需选主播；开播一次选完 |
| 音色不支持泰语也能播，太死板 | **不传语言参数**，语言只体现在文本里；音色×语种是"试过/没试过"的记录，没试过只给提示 | 泰语文本 + 中文音色直接能合成出声；未试过的只显示提示，不阻断 |
| 有些模型根本不存在 | 官方文档核对 + 配置化清单 | 逐个模型能说出出处 |
| 跨境看不懂 | 双字段 + 对照显示 | 泰语节目播出时中文小字同步可见 |
| 点播放可选清空重合成或复用 | 开播配置⑥音频策略 | 两条路径各开播一次，核对就绪条数与耗时 |
| 每条要显示对应主播（双人/团体） | 行首主播徽标 + 说话人时间线 | 双主播剧本播出时颜色与名字同步 |

## 二十一、待确认

1. **配置弹窗预填**：每次必弹，字段预填上次值（不写回资产）；若要每次全空白，改一处即可。
2. **离线写稿语言**：不开播时用剧本的「写稿语言」；未设置则弹小选择，默认中文。
3. **话术模板是否跨主播复用**：建议允许但强制标黄，不自动套用。
4. **无限生成上限**：建议每场设"最多连续生成 N 分钟 / N 条"，到顶提示续费/继续。
5. **历史留存**：本场内全量保留；跨场进场次记录；超过 30 天且未导出的场次，音频可归档只留文本。
6. **语言参数**：默认**不传**（语言只体现在文本里）。若某家接入确实支持 `language` 参数、且实测有收益，只在适配层作为可选提示透传，不进 UI、不参与校验——待模型清单核对后逐家决定。
7. **语种实测样本存哪**：建议存进 blobs（asset 级，不随缓存清理），每对「音色 × 语种」保留最近一条，供开播前试听比对。
