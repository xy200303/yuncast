# 界面一览

左侧边栏从上到下是 **直播台、节目**，然后分两组：**资产库**（主播团、知识库、音色库）、**数据**（场次记录、统计），最下面是「设置」。侧边栏可以收成一列图标，图标上悬停显示名称。

底部状态栏常驻，左边是 `就绪 / 播报中 / 已暂停 · 当前页面` 和一段主输出电平音波（有内容在播时才起伏），右边四个格子：

| 格子 | 显示内容 | 异常时 |
| ---- | -------- | ------ |
| 导演 | `导演 名字（服务商）` | 红字「导演大脑未配置 → 去配置」，点进「设置 → 导演」 |
| 卡司嗓音 | `卡司嗓音 嗓音（服务商）` | 卡司第一张的嗓音；路由断了提示「卡司嗓音失效 → 去修复」，点进「设置 → 语音合成」 |
| 推流 | 直推显示 `推流中 N kbps` / `未推流`；伴侣模式显示 `伴侣出声` / `未出声`，断线显示 `重连中(N)` | 推流出错标红 |
| 连接器 | `连接器已连接 / 连接中… / 未接入` | 连接失败时显示重试中 |

配置都齐了这几格才是正常色，所以开播前先扫一眼这一行。有段落在合成时会多一格「合成中 N」。

## 直播台

开播主控台。左栏三个选项卡：`接下来 · N / 评论流 · N / 事件流 · N`；节目关掉「直播间动态」时不出选项卡，直接显示「接下来」。

「接下来」的内容跟着播出方式变：

- **全部做好再播**：章节列表，每章显示时长或 等待合成 / 合成中 / 失败 / 文稿已修改，正在播的标「播报中」，点就绪的章立即跳播
- **现场发挥**：实况视图
- **边播边准备**：话术池队列，每条带档位色点（打断 / 下一条 / 垫底）、来源（剧情、回复、互动、公告、暖场、手动、捧场）、回复对象、音色和状态图标；鼠标悬停出「撤销这条」，5 分钟内合成失败的单独列在底部

资产（人设、模型、剧本）改过之后，列表顶部会出现黄色提示条，带「立即应用」——点了当前对话上下文清空，主播换用新版。

播控都在**底部吸底播放条**：

- 左槽：节目名（未开播可点开换节目，直播中只读），下面一行是节目卡司与默认嗓音
- 中槽：未开播时只有「启动节目」；开播后是 暂停 / 继续、跳过当前这条、队列、结束本场（红字，二次确认，和「暂停」是两个动作）。预制节目还有上一章 / 下一章，并把按钮换成章节跳转
- 右槽：静音按钮与主音量滑杆（拖到 0 等于急停 AI 两路声音），以及「⋯」菜单

预制节目在播放条顶部有一条贴边进度线，可以按住拖动跳到指定位置；副标题显示 播放位置 / 时长。滚动与即兴节目没有确定时长，这条线不显示。

「⋯」菜单里是两件人工干预的事：

- **人工播报**：输入文本丢进话术池，选插播方式——「排队等播」排在已排队内容之后，「插为下一条」当前这条播完就播；音色留空就用主播自己的
- **自动响应**：开关「让主播看到直播间动态」，再勾选这一场要开哪些触发器（内建的最多六类，见[核心概念](/guide/concepts)）；直播中也能改，改完立刻生效

**导演对话面板**平时是右下角一个悬浮球（悬停提示「打开导演」），点开停靠到右侧，面板可以切成悬浮窗或收起来，`Ctrl+J` 也能唤起。时间线按事件原样渲染：

- 你发的指令是右侧气泡，可以带附件（png / jpg / webp / gif / pdf / docx / txt / md；图片要模型开了多模态才会真的进会话）
- 思考过程默认折叠，点开能看到内容，标题带耗时
- 工具卡说人话（「查了商品资料」「安排了播报 ×4」），点开才看参数与结果
- 请示卡带一键选项、默认策略和倒计时，没答就按默认策略继续，不阻塞直播
- 输入框下方三个快捷按钮：暂停 / 跳过这条 / 汇报下状态，其中暂停和跳过是本地直接执行，不过模型

输入框右下角的圆环是上下文仪表，悬停显示「导演的短期记忆已用 N%」，快满时自动整理。这里要说清一件事：**对话框里的内容只进对话，不会被播出去**，要出声得用「人工播报」或者让主播用播报工具。

## 节目

节目是配置模板。卡片上有节目名、「当前节目」徽章、主题、三个标签（内容类型 / 播出方式 / 绑的剧本，没绑就写「未绑剧本」），以及状态行：预制节目显示 `音频 就绪数/总数 · 失败 N · 文稿已修改 N · 合成中 N`（计数单位跟着内容类型，是段 / 个环节 / 章 / 场），滚动节目显示 `底稿 N 段 · 音频就绪 N`。

卡片上的按钮按状态出现：去生成底稿、继续写稿、继续合成、播放、设为当前 / 取消当前、底稿库（现场发挥没有这一栏）、配置、导出、删除。预制节目音频齐了会出现「播放」，点了就是切换当前节目并启动。

编辑弹窗里能配：名称、剧本 / 文章、内容类型、主题与节目说明、播出方式、播完以后（现场发挥没有）、事件规则（一行摘要，点进内页勾选启用哪些触发器、要不要把直播间动态喂给主播）、卡司、知识范围。卡司留空表示导演自选，全部主播卡都是候选人。这里**没有「声音」这一栏**（出谁由卡司定），另有一个「节目风格指令」管整期默认演法。

「底稿库」打开底稿工作台，标题栏先给状态：`N 段 · 就绪 N · 合成中 N · 待合成 N · 失败 N`。工具栏是 AI 写稿（现场发挥没有）／手动新建，右侧是清空全部（再点一次确认）、清空音频（文稿保留、回到待合成，外部导入的音频不动）；滚动节目多一个「提前合成全部」。

预制节目在工作台底部还有音频进度区：逐单元看状态，失败的、文稿改过的可以单独重试，也可以给某个单元「导入外部音频」跳过合成。

「合成声音」弹窗是所有合成入口的统一前置，先告诉你「本次合成 N 段 · 约 X 分钟」（已就绪且文稿未改的自动跳过），再让声音二选一：① 卡司嗓音（节目卡司第一张）；② 选择其他音色…（接入 → 模型 → 音色，也能手填音色 ID）。选到播客模型要指定主持人 A / B，并选择要不要开场、结尾音乐。已有别的嗓音的成品时给混音提醒和「全部重合成，统一为本次选的声音」。**声音就是这时候定下来的，选完冻结进每一段产物。**

## 主播团

人设卡列表，每张卡显示名字、性格前两行、嗓子（没选就写「还没选（必选）」）和这把嗓子的能力徽章，点卡片开编辑弹窗，配性格、口癖、禁区、音色。谁上场由节目卡司（节目配置里多选）决定，没配卡司就由导演逐条指定。

主播只管人设与表达风格：谁上场由节目卡司和导演决定，大脑在设置里的「导演」，启停归播出流程，这一页都不管。

## 知识库

三个选项卡：`条目 · N / 资料文件 · N / 剧本 · N`。

- **条目**：商品、书籍 / 读物、话题 / 节目、自定义四类，可筛选。价格护栏只认商品条目——主播报价只认这里核过的口径，不会自己编数字。连接器已连接时可以用「从抖音商城同步」拉商品
- **资料文件**：上传 txt / md / docx / pdf 与图片，解析入库后参与检索
- **剧本**：给节目绑的剧本与场景

## 音色库

克隆音色的管理与试听，外加各接入下可用的云端音色。顶部可以按接入筛选、刷新列表，点「新建音色」打开「新建音色（声音克隆）」弹窗：

1. 选**接入**（复刻在服务商那边做，用它的凭据）
2. 选**目标模型**——音色与模型绑死，之后不能跨模型使用；接入里没有可复刻的模型时会提示先去勾上「复刻模型」
3. 交**样本**：建议 10–30 秒清晰人声、无背景音乐，可以上传文件或现场录音，提交时会自动转成 mp3
4. 百炼复刻只认公网可访问的样本地址，点「上传样本并取地址」把本地样本换成直链
5. 勾选「我确认已获得录音人的明确授权」，提交克隆

火山复刻由服务商异步训练（界面提示通常秒级完成），本页会自动更新状态；账号需已开通「声音复刻」，复刻音色在服务商侧走后付费：首次正式合成即转正计费，试听 7 天没有正式调用会被删除。百炼创建即完成、音色长期有效，但创建时绑定的目标模型之后不能改。删除音色会连样本文件一起删掉，**平台侧的复刻音色要在服务商控制台单独清理**。

## 场次记录

左侧是场次列表，每场显示：节目名、结束标记（进行中 / 手动收播 / 播完收播 / 紧急停止 / 应用退出 / 异常中断）、开播时间与时长、导演模型、卡司，以及 `播出 N 条 · 评论 N 条 · 回复 N 条`。

点进一场看留档：顶部同样是这几个数字，可「导出音频」按实际播出顺序导出整场，也可以删掉这场；下面是四个选项卡——时间线（逐条话术，可试听）、图表、观众 · N（进场观众与他们的言行）、复盘摘要，另有 时长 / 播出段数 / 评论数 / 互动观众数 四个指标卡。

## 统计

顶部是统一的筛选：时间范围（近 7 天 / 近 30 天 / 近 90 天 / 全部）加节目筛选（全部节目或某一场节目）。三个选项卡：

- **概览**：总场次、总播出时长、总评论数、总合成时长（按 4 字/秒折算）、累计观众，配播出趋势与互动趋势图
- **排行与热词**：节目排行、主播排行，以及评论热词与话术热词两张词云
- **用量**：近 30 天用量趋势、按节目分布（累计），以及两张明细表——`LLM 请求 · N`（时间 / 节目 / 用途 / 模型 / 输入 / 输出 / 缓存命中）和 `TTS 合成 · N`（时间 / 节目 / 模型 / 音色 / 字符数），各显示最近 100 条

## 设置

八个栏目：

- **外观**：明暗模式（浅色 / 深色 / 跟随系统）与配色主题（点缀色，作用于按钮和选中态）
- **导演**：导演名字、接入、模型。全局唯一的大脑，思考、派活、写稿全靠它
- **语言模型**：接入库。一条「接入」＝一家服务商 + 一份凭据 + 一组模型；服务商可选 OpenAI 兼容通道（DeepSeek、通义千问、豆包、Kimi、智谱）、OpenAI 官方 Responses、Anthropic（Claude 与 Kimi 编程端点）、自定义接口。协议收在「高级：API 协议」折叠条里。模型行末尾的扳手配高级参数：上下文窗口、思考强度、多模态、温度、回复上限。整条接入可以「测试连通」，也能逐个模型测
- **导演手册**：导演的脑子由这些提示词模板组装（身份与工作方式、指令包装、直播间动态注入、写稿任务书、上下文压缩等），变量用 `{{变量名}}` 占位，改完保存要重开会话才生效，可逐条恢复默认
- **语音合成**：接入列表，一条接入＝一个服务商账号，凭据、模型勾选、每个模型的参数、实时合成开关都在里面；同样的「测试合成」会用当前表单值真合成一句出声
- **推流**：伴侣模式（只出声，画面交给你的直播软件）或直推 RTMP（FFmpeg 静态帧 + 混音）。直推要填服务器地址和推流密钥，页面上有开始 / 停止推流
- **连接器**：端口与连接令牌，填完「保存并重连」，也可以「立即重连」。状态徽章显示 未连接 / 连接中 / 已连接 · 收 N 条 / 连接失败（自动重试中）
- **关于**：版本、GitHub 与官网入口、检查更新（走 GitHub Releases，可下载并重启安装）、重新打开新手指引、反馈问题与更新日志

评论接入单独说：主程序不内置任何平台 SDK，也没有内置评论模拟器。「连接器」靠一个单独的小软件——抖音「直播数据助手」。装好打开它，把它「设置 → 智能体接口」里的端口和令牌抄进这里，评论 / 礼物 / 进场就会流进来。连接走的是本机回环地址，默认端口 `8102`。
