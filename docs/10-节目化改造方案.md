# 10 · 节目化改造方案（待审核版）

> 状态：**待审核，未实施**。审核通过后按 Roadmap 分期执行。
> 前置：场次↔主播解耦（Step 1-5，已完成）是本方案的地基。

## 1. 目标

把软件从"直播工具"升级为"语音内容工作台"：

- **平台无关**：节目是直播/有声书/播客/广播剧，渠道是抖音/任意平台，两者正交
- **生产与播出分离**：有声书/播客走"全部做完→审听→导出"流水线；直播走"边播边产"
- **语气一致性**：合成策略可配（逐段/整块/整篇），消灭段间语气断裂
- **形态可扩展**：新形式 = 加语义标签 + 任务书模板，引擎零改动

## 2. 概念模型（最终版）

### 2.1 两个层次

| 层 | 职责 | 内容 |
|---|---|---|
| **format 语义标签** | 告诉 agent/系统"这是什么内容形态" | 4 个枚举值，进 system prompt 与写稿任务书 |
| **配置子项（平铺）** | 告诉引擎"机器怎么跑" | 交互/合成/轮播/生产/写稿五组，创建时按 format 填默认值，可随意覆盖 |

format 在引擎里**不存在**（不吃 format 字符串，只吃解析后的配置）；配置子项在 agent 的写稿语义里**不存在**（写什么由 format 定）。

### 2.2 format 四值与默认配置矩阵

| format | 语义 | 交互默认 | 合成默认 | 轮播默认 | 生产默认 |
|---|---|---|---|---|---|
| `live` 直播 | 有观众、实时、可能互动 | batched 接线，触发器开 | segment 逐段 + 上文 hint | 队列+车道+循环闸门 | 边播边产 |
| `podcast` 播客 | 对谈/单口、成期 | 关 | whole 整期（双人=火山 PodcastAPI，单口=localChain） | 整期连播+章间过场 | 流水线 |
| `audiobook` 有声书 | 旁白讲述、章节、无听众 | 关 | whole 批量整章（localChain） | 章节顺序+书签 | 流水线+导出 |
| `drama` 广播剧 | 多角色演绎、剧本 | 关 | whole 批量整章+多角色路由 | 章节顺序+音效轨 | 流水线+导出 |

### 2.3 内置场景 = format + 覆盖项（不再是独立层）

| 场景 | = |
|---|---|
| 纯直播/宣讲/带货 | live（默认） |
| 交互直播 | live + 交互拉满（full 接线+节拍器+冷场自救+话题卡）+ 实时流式合成 |
| 情感电台/陪伴 | live + 常驻循环 + BGM 主导 + filler 垫底 |
| 值守循环（门店背景音） | live + 循环 + 交互关 |
| 单口播客 | podcast + 单口参数 |
| 双人脱口秀 | podcast + 双人参数（火山后端） |
| 单人有声书/评书/讲书 | audiobook |
| 多角色广播剧 | drama |
| 睡前故事连载 | audiobook + 章节即故事 |

## 3. 配置子项全清单（program 平铺字段）

```
交互组 interaction:
  comments        off | batched | full      （评论接线）
  commentBatchSec 秒                         （batched 窗口）
  triggersEnabled bool                       （触发器总开关）
  metronome       bool                       （节拍器：整点带节奏，防冷场）
  coldRescue      bool                       （冷场自救）

合成组 synth:
  strategy        segment | block | whole
  wholeBackend    localChain | volcPodcast   （whole 的后端；volcPodcast 仅支持双人）
  blockSize       3~5 段                     （block 模式的块大小）
  prevHint        bool                       （逐段模式带上一段文本做韵律 hint）

轮播组 playback:
  loop            bool                       （播完整轮从头再来）
  resident        bool                       （常驻：无明确结束）
  gapMs           段间留白
  bgmRole         none | background | bridge （BGM：关/背景主导/章间过场）
  sfxTrack        bool                       （音效轨：广播剧）

生产组 production:
  mode            realtime | pipeline       （边播边产 | 全部做完）
  exportEnabled   bool                       （导出器开关）

写稿组 writing:
  targetMinutes   目标时长                   （任务书参数，模板由 format 定）
  chapterCount    章数/期数（audiobook/drama）
  cast            角色表引用（drama/podcast 双人）
```

**默认值快照进节目**：创建时按 format 生成，之后改节目不影响别的节目，改 format 定义不影响存量。

## 4. 数据模型变更

| 变更 | 说明 |
|---|---|
| `live_plans` → `programs` | 表改名 + 上节平铺字段（interaction/synth/playback/production/writing 五个 JSON 列或前缀列） |
| `LivePlan.format` | 新增，4 枚举 |
| `LivePlan.modeId` | **退役**（modes 表吸收进 interaction 组；modes 内置行的接线配置并入 format 默认值） |
| `LivePlan.voiceId` | 已 @deprecated，本轮删除该列 |
| `speech_items` | 加 `positionMs`/`durationMs`（长音频进度）；条目即"播出项"（段/章/期通用） |
| `utterances` | 加块归属/段落偏移表（whole 模式定位重合成点）；支持挂外部音频（`synthVoice='external'`，合成跳过） |
| 无 `formats` 表 | format 是 types.ts 里的语义定义 + 默认配置生成函数 |

## 5. 合成系统

### 5.1 三档策略

| 策略 | 做法 | 一致性 | 适用 |
|---|---|---|---|
| segment 逐段 | 每段一次 TTS；开 prevHint 时带上段尾文本 | 差→中 | 直播 |
| block 整块 | 一次 TTS 吞 3~5 个自然段 | 好 | FM/轻互动 |
| whole 整篇 | 整章/整期一气合成，一个长音频 | 最好 | 播客/有声书/广播剧 |

### 5.2 whole 双后端

- **localChain**：自家 TTS 按自然段连续调用（同一 style 参数），拼接成一个文件。单口/有声书/广播剧唯一后端（多角色走角色音色路由）
- **volcPodcast**：火山引擎 PodcastAPI（action=3 直喂双人对话文本，agent 编剧模式稿）。仅 podcast 双人场景
- **自动降级**：volcPodcast 失败（风控/配额）→ 落 localChain 重蒸，节目不断

### 5.3 批量合成调度器（pipeline 模式）

- 按章/期排队，顺序慢蒸，**限流避让**（429 退避），按章重试，中断续蒸
- 与直播的合成窗口（前 5 条滚动）并存：realtime 模式用窗口，pipeline 用调度器
- 整章进度条：第 x/y 章，当前章百分比

### 5.4 轮次偏移表

- 362 事件（火山）/ 自家切段记录：每段在整篇音频里的 start/end
- 用途：改稿定位重蒸点、进度书签、导出写章节元数据

## 6. 导出器（audiobook/drama/podcast）

- 按章分文件：`《书名》-001-第一章.mp3`（命名模板可配）+ 章节目录
- 合并整本：单文件 + 章节标记
- **响度归一化**（≈-14 LUFS 可选）
- ID3 元数据：书名/作者/演播者/封面
- 格式：mp3 / wav（母带）

## 7. 工具箱（不建节目，复用 TTS 层+导出器）

| 工具 | 输入 | 输出 |
|---|---|---|
| 配音工作台 | 口播稿（agent 可代写）+ 音色 | 按条 mp3（短视频/广告旁白） |
| 文章转语音 | 粘贴链接/文本 | 朗读音频 |
| 提示音素材库 | 短语列表 | 批量合成导出（IVR/门店） |

## 8. 通用播控台（三张脸）

骨架四层：顶栏（节目/开始结束/状态）· 播出区（当前项大卡片）· 内容区（内容列表）· 侧栏（导演对话 + 条件显示互动区）。

| 脸 | format | 内容区 | 当前项 | 互动区 |
|---|---|---|---|---|
| 队列脸 | live(segment) | 底稿队列（车道/状态） | 一条段 | 全开 |
| 长文脸 | audiobook/podcast/drama(pipeline) | 章节/期列表 | 整章/期：进度条+seek+书签 | 关 |
| 即兴脸 | live 交互型 | 最近说过的话 | 流式状态 | 全开+话题卡 |

- 话术池面板更名"播出队列"，条目通用化（段/章/期）
- 推流目标按节目记忆；任何 format × 任何平台
- 预检按 format 换检查项

原型：`docs/mockups/program-console.html`（三脸切换）、`program-library.html`（节目库+编辑）、`toolbox-export.html`（工具箱+导出）。

## 9. agent 任务书（按 format 一套模板）

| format | 任务书 |
|---|---|
| live | 场景底稿逐段写 + 低水位补货（现有） |
| live 交互型 | 无稿；话题卡弹药 + 节拍器 + 冷场自救策略 |
| podcast | 整期结构（开场→话题→收尾），单口/双人；双人用 role 标注轮次 |
| audiobook | 按章写稿 + 全书大纲一致性（人物/旁白口吻注入） |
| drama | 剧本格式：角色台词 + 旁白 + 音效标注（sfx 进音效轨） |

system prompt 增「节目形态」模块（format + 语气范式 + 互动姿态 + 形态禁区）。

## 10. 术语改名

场次→节目；话术池→播出队列；底稿/话术库→文稿（库）；直播台→播控台；启动/结束场次→开始/结束播出；直播模式→（退役并入交互组）；话术→（语境区分：段=queue item，稿=utterance 改名文稿）。

## 11. Roadmap

| 期 | 内容 | 产出 |
|---|---|---|
| **P1** | 逐段合成上文 hint（prevHint：带段尾文本调 TTS） | 直播听感立即改善，零结构改动 |
| **P2** | 改名+format+配置子项+modes 退役；数据迁移 | 概念层落地，live 行为不变 |
| **P2.5** | 通用播控台三张脸 + 长音频条目/进度落库 | UI 落地 |
| **P3** | 合成策略三档 + 双后端 + 批量调度器 + 导出器 | 播客/有声书可用 |
| **P4** | 任务书模板（podcast/audiobook/drama）+ 角色映射 + 音效轨 + 工具箱 | 场景闭环 |
| **P5** | 火山 PodcastAPI 客户端对接（随 P3 whole 后端一起做也可） | 双人播客 |

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| 整篇 TTS 单次文本上限 | whole = 一次任务内部按段连续调用拼接，上层一个文件 |
| 长音频中途改稿 | 偏移表定位，从改动点之后重蒸 |
| 火山 API 风控/限流 | 自动降级 localChain；429 退避 |
| 改名触碰面大 | 开发期全局一次改，越早越便宜 |
| 交互直播烧 token | 节拍器防冷场而非防思考；话题卡降低生成成本 |
